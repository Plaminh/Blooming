# Data Model

No new database tables will be introduced. We will reuse the existing tables.

## Existing Database Models Used

### `PlanningSession` (`app.db.models.planning`)
- **id**: UUID (Primary Key)
- **user_id**: UUID (Foreign Key to users)
- **session_type**: String (e.g., 'DAILY_PLAN', 'PLAN_EDIT')
- **status**: String ('OPEN', 'AWAITING_CLARIFICATION', 'COMPLETED', 'CANCELLED')
- **context_date**: Date

### `PlanningMessage` (`app.db.models.planning`)
- **id**: UUID
- **planning_session_id**: UUID (Foreign Key)
- **role**: String ('USER', 'ASSISTANT', 'SYSTEM')
- **content**: Text
- **structured_payload**: JSONB (Stores `TodayDraft` or `RoadmapDraft`)

### `Task` (`app.db.models.tasks`)
- Reused to store normalized task details generated by AI.
- `priority` mapping: ('LOW', 'MEDIUM', 'HIGH', 'URGENT')
- Uses `fixed_start_at`, `fixed_end_at`, `deadline_at`, `is_splittable`, and `TaskDependency` natively.
