# Blooming frontend agent notes

Intended UI stack: **Tauri 2 / Rust** + **Svelte + TypeScript + Vite**.

This `frontend/` directory may still contain leftover Next.js scaffolding. Do not implement Blooming as a Next.js, React, or web-only application. Do not add OS toast notifications, widget LLM chat, plant inventory, or weather-driven planning.
